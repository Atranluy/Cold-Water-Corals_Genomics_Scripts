# File conversion scripts
## Overview
In this repository, you will find different folders and README files that provide scripts for file conversion of the VCF to different format.

## Repository Structure
- **dadi_sfs_1D/**: Contains the python script to generate the 1D SFS per population using dadi 
- **Treemix/**: Contains the bash script using vcftools to generate treemix format file (count of alleles per populations) 
- **VCF_to_CDS_Fasta_DILS/**: Contains all scripts to convert VCF with invariant position into Fasta formats for DILS

## Usage
Each folder contains specific scripts along with a README file that provides detailed information on how to use the scripts within that folder.
NB: Scripts are written for PBS HPC job scheduler , if you're using a Slurm0 HPC job scheduler, you will need to adapt all scripts.
